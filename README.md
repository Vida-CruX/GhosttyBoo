# Ghostty Boo Screen Saver

A tiny haunted terminal, now living in your macOS screen saver.

This project ports Ghostty’s delightful **Boo** animation into a native macOS screen saver.  
No terminal window. No commands. Just Boo drifting through the dark when your Mac falls asleep.

## Installation

Download the latest .zip file from the **Releases** page and extract it.

Then either:

1. Double-click the `.saver` file, or
2. Copy it to:

```bash
~/Library/Screen Savers/
```
Then open: System Settings → Screen Saver. Select Ghostty Boo Screen Saver.
